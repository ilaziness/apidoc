## 1. 背景与目标

需要一款本机可用的 API 文档管理工具：**文档集是顶层**（对标 Apifox 的「项目」），其下用树管理分类、说明页和接口。第一期只做 **HTTP** 协议的文档编辑与请求发送。

当前**不做**账号登录、多人协作、云同步。后续会自建**中心化同步 / 协作服务器**。第一期数据模型与协议抽象必须留口，但不能在本期实现服务端。

### 1.1 本期成功标准

- 文档集是顶层容器：可创建多个并切换。一个文档集 ≈ Apifox 的一个 **API 项目**。
- 文档集内维护树：文件夹、Markdown 说明页、HTTP 接口。
- 可编辑 HTTP 接口并发送请求、查看响应（可取消、可并行多个）。
- 文档集内多环境切换；`{{key}}` 能替换则替换，不能则**原文发送**。
- 可从 OpenAPI / Swagger **本地文件或 URL** 导入（自动认 2.0 / 3.0 / 3.1）。本期不导出。
- 业务数据在 `{HOME}/.apidoc` 的 SQLite；设置里可改数据目录；应用配置与数据目录分开。
- 无登录。协议字段可扩展，本期只运行 HTTP。

## 3. 明确不做（本期）

- 用户注册、登录、SSO、权限、**团队 / 工作区层**（对标 Apifox 团队）、同步、分享、评论。
- 自建协作服务器。
- gRPC / TCP / UDP / WebSocket 的编辑与发送（仅数据层预留枚举）。
- OAuth 2.0；Cookie 罐；客户端证书；HTTP/2；流式响应。
- OpenAPI 导出；剪贴板粘贴导入；Postman Collection 导入/导出。
- 请求历史；TRACE / CONNECT / 自定义 Method；独立 GraphQL 编辑器。
- SOCKS5 代理；接口级代理（代理只在设置里全局配置）。
- 根据 OpenAPI `servers` 自动建环境。
- 跨文档集的全局环境；工作区/团队级鉴权。
- 加密存储密钥（本期明文进 SQLite）。
- 示例数据（首次启动为空）。
- 全文搜索；节点/文档集「复制一份」；Mock；测试脚本；代码生成。
- WASM / 浏览器版；自动更新；崩溃上报；go-gui headless UI 自动化测试。
- go-edit 语法高亮（响应 JSON 只做格式化，不用 go-edit）。

安装包具体形态、最低 OS 版本、日志方案：后期再定；不阻塞第一期源码能编过、能跑。

## 4. 用户与场景

本机使用者。无多角色。

1. 打开应用（空列表）→ 新建文档集，或导入 OpenAPI。  
2. 建文件夹、Markdown、HTTP 接口；改完点**保存**。  
3. 配置环境并切换。  
4. 编辑方法、URL、路径参数、Query/Header（可禁用行）、Body、鉴权、超时/重定向/TLS。  
5. 发送（可并行、可取消），看状态码、耗时、头、Body（JSON 则格式化）。  
6. 设置中改语言、主题、全局代理、数据目录。

## 5. 核心概念

| 概念 | 说明 |
| --- | --- |
| 文档集 | **本期顶层**。对标 Apifox **项目**：一份独立的 API 文档 + 调试空间。含一棵树、本集环境、本集默认鉴权。本机可有多个文档集并切换。 |
| 文件夹 / Markdown 页 / HTTP 接口 | 树节点。 |
| 协议 | `http` 本期实现。预留且不可创建：`grpc`、`tcp`、`udp`、`websocket`。 |

| 变量 | 仅 `{{key}}`：区分大小写、**不**修剪空格、**不**支持嵌套。匹配则替换，否则原文发送。 |
| 回收站 | 删除的文档集与节点先入回收站。可还原、可清空；**默认 30 天后自动永久删除**。 |
| 用户数据目录 | 默认 `{HOME}/.apidoc`，可改。 |
| 应用配置 | 语言、主题、数据目录路径。与业务库分离。 |

## 6. 功能需求（已确认）

### 6.1 文档集

- 创建、重命名、删除（进回收站，删除前确认）。回收站可还原、可清空；条目保留 **30 天** 后自动永久删除。
- 切换当前文档集。
- 本集独立的树、环境、默认鉴权。
- **保存当前节点**才写入 SQLite。切换节点且有未保存改动时弹出确认：保存 / 丢弃 / 取消切换。
- 重启后恢复：上次的**文档集、当前环境**；不恢复选中的树节点。

### 6.2 内容树

- 节点：文件夹、HTTP 接口、Markdown。
- 创建、重命名、删除（回收站）、调整父子与同级顺序。
- 选中后主区编辑。类型要能从树上区分。
- 本期不能创建非 HTTP 协议节点；库表仍存 `protocol`。

### 6.3 Markdown

- 可编辑源文，可预览。源码/预览分栏或 Tab：后期再定，第一期任选一种能用的即可（实现时不要再加第二种）。

### 6.4 HTTP 接口

字段：名称、Method、URL、路径参数栏、Query（行启用勾选）、Header（行启用勾选）、Body、鉴权（覆盖文档集默认）、超时、跟随重定向、是否跳过 TLS。

运行：

- 当前环境替换变量后发送。
- 路径参数写入 URL 中对应 `{name}`。
- 未勾选的 Query/Header 行不发送。
- 可取消；可并行多个请求。
- 响应：状态码、耗时、Header、Body；JSON 则格式化。Body 超过 **10MB** 截断并提示。不保存历史。
- 不在接口上配置代理。

#### 6.4.1 Method

要：GET、POST、PUT、PATCH、DELETE、HEAD、OPTIONS。  
不要：TRACE、CONNECT、自定义。

#### 6.4.2 Body

要：none、JSON、x-www-form-urlencoded、multipart/form-data、raw（可指定 Content-Type）、binary。  
不要：独立 GraphQL 编辑器。

#### 6.4.3 传输默认值（新接口）

| 项 | 默认 |
| --- | --- |
| 超时 | 60 秒 |
| 跟随重定向 | 是 |
| 跳过 TLS 校验 | 否（校验证书） |
| 代理 | 使用设置里的全局代理；全局默认「系统代理」。无 SOCKS5。接口上不可再配代理。 |

用户可在接口上改超时、重定向、是否跳过 TLS；改完须保存。

### 6.5 鉴权

No Auth、Bearer、Basic、API Key（Header 或 Query）。不要 OAuth 2.0 等。

文档集默认鉴权 + 接口覆盖（可覆盖为 No Auth）。发送用覆盖后的结果。

### 6.6 环境

- 文档集内多环境，可增删改名、编辑键值、切换当前。
- 替换范围：URL、路径参数、Query、Header、Body、鉴权。
- 只有环境键值，没有文档集级「公共变量」层。

### 6.7 OpenAPI 导入

- 仅本地文件、URL GET。JSON/YAML。版本 2.0 / 3.0.x / 3.1.x 自动识别。
- 每次询问：新建文档集，或导入当前文档集。
- 导入当前集时同名文件夹/接口：**覆盖**。
- `tags` → 文件夹；每个 path + method → 一个 HTTP 节点。
- 无 tag → 放入名为「未分组」的文件夹（中文界面；英文界面文案用 `Untagged`）。
- **不**用 `servers` 自动建环境。

### 6.8 数据、设置、目录

- 业务库：默认 `{HOME}/.apidoc`。
- 应用配置目录（语言、主题、数据目录路径、全局代理）：
  - Windows：`%APPDATA%\apidoc`
  - macOS：`~/Library/Application Support/apidoc`
  - Linux：`~/.config/apidoc`
- 改数据目录：先提示将复制且同名覆盖 → 用户确认 → **先复制** → 成功才写入路径配置 → 提示结果并**必须重启**后才用新目录。失败则配置仍指向旧目录。本次进程在重启前仍用旧目录。不删除旧目录。
- 密钥：**明文**存 SQLite。
- 不支持同时打开第二份独立库文件。

### 6.9 设置项（本期）

用户数据目录、界面语言、主题、**全局 HTTP/HTTPS 代理**（三档：**系统代理** / **不使用代理** / **手动填写代理 URL**）。默认系统代理。无 SOCKS5。

### 6.10 许可证

MIT。实现阶段在仓库根目录放置 `LICENSE`。

## 7. 界面

- go-gui，禁止 Electron / 浏览器壳。
- Windows / macOS / Linux，**amd64 + arm64**。
- **单实例**：第二次启动只激活已有窗口。
- **首次**：无示例数据。
- 分区：文档集列表/切换、树、节点编辑、HTTP 响应、环境切换、设置、回收站入口。
- 语言：中/英，设置切换；首次跟 OS（中文系 → 中文，否则英文）。
- 主题：浅色 / 深色 / 跟随系统；首次跟随系统。

## 10. 技术

| 项 | 选择 |
| --- | --- |
| Go | `go.mod`：`go 1.27` + `toolchain go1.27.3`（跟进官方最新稳定版）。go-gui 语言下限 1.26+，不得降到其下。 |
| 模块路径 | `github.com/ilaziness/apidoc`（与 GitHub remote 一致） |
| UI | `github.com/go-gui-org/go-gui` |
| macOS | Metal 需 CGO；SQLite **仍禁止** mattn/go-sqlite3 |
| ORM | Bun + `sqlitedialect`；迁移在 `internal/store`（脚本放 `store/migrations/`） |
| SQLite 驱动 | `modernc.org/sqlite`（纯 Go） |
| 启动 | 读应用配置 → 打开 `{数据目录}` 库 → migrate → UI |

分层：`ui` / `service` / `protocol`（含 `httpapi`）/ `store` / `openapi` / `config`。UI 不拼 SQL。HTTP 实现包名用 `httpapi`，避免与标准库 `net/http` 冲突。不设独立的顶层 `migrate` / `app` 包。
